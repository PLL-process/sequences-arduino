Concevoir un jardin qui arrose seulement quand il le faut

Les élèves relient le vivant, les capteurs, l’algorithmique, l’énergie et le développement durable pour construire un système d’arrosage connecté sûr, économe et réparable.

▶ Commencer le parcours Découvrir les séances

Cette page présente le projet. Le jumeau numérique, les défis Python et les évaluations se trouvent uniquement dans les huit séances afin d’éviter tout doublon avec la séance 1.

Situation déclenchante

Comment préserver les plantes pendant les périodes chaudes sans gaspiller l’eau ?

Le système devra mesurer l’humidité du sol, surveiller le niveau du réservoir, prendre une décision, commander une pompe en très basse tension, informer l’utilisateur et rester maintenable dans le temps.

Architecture pédagogique

Deux représentations complémentaires dans chaque séance

1Observer le réelReconnaître l’Arduino, les capteurs, le relais, la pompe et l’alimentation séparée.
2Comprendre le schémaLire les chaînes d’information et d’énergie, les signaux et les fonctions techniques.
3Tester le jumeau numériqueExpérimenter sans risque, observer les flux et vérifier les décisions du système.
4Construire le programmeCompléter un modèle incomplet, tester puis justifier la solution sans recevoir la réponse à l’avance.
