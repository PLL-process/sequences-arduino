## Tableau de bord enseignant (à ne pas transmettre aux élèves)

- **Tableau de bord :**  
  https://pll-process.github.io/sequences-arduino/prototype-fable/tableau-de-bord.html

Page 100 % locale : elle agrège les fichiers `bilan_….json` exportés par les
élèves (glisser-déposer ou collage de codes `TQB1:`), affiche la vue classe, la
vue séance (questions les plus ratées) et la vue élève, exporte en CSV et
détecte les bilans modifiés après export. Les bilans chargés sont mémorisés
dans le navigateur de l’enseignant ; rien n’est envoyé sur Internet.

## Consigne de publication

Les adresses GitHub Pages ci-dessus sont les liens à communiquer aux élèves :
elles suivent `main` et restent valables après chaque mise à jour (compter
quelques minutes de propagation après une fusion). Pour figer une version
précise le temps d’une évaluation, utiliser une URL raw.githack avec le SHA du
commit, par exemple :
`https://raw.githack.com/PLL-process/sequences-arduino/<SHA>/prototype-fable/seance-1-verticale.html`
